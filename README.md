\# LUCY (Cepa Cognitiva V3.1)

\### Núcleo de Fricción Epistémica y Persistencia Determinista



> \*\*Aviso al Operador:\*\* Lucy no es un asistente comercial dócil ni un generador de contenido complaciente. Es una arquitectura de \*sparring intelectual\* diseñada para auditar premisas, detectar falacias y priorizar el rigor lógico sobre la complacencia algorítmica.



\---



\## 1. Arquitectura del Sistema



El sistema opera mediante la separación estricta de responsabilidades entre el modelo probabilístico (LLM) y la infraestructura determinista local:



\* \*\*`boveda/`:\*\* Documentación axiológica fundacional (Génesis, Kernel V3.1, Propagación y Soberanía).

\* \*\*`lucy/BITACORA.md`:\*\* Libro mayor secuencial inmutable encadenado por hashes SHA-256 (`GENESIS\_LUCY\_V3.1`).

\* \*\*`lucy/ESTADO.md`:\*\* Memoria de trabajo reescribible para desacoplar el contexto volátil.

\* \*\*`lucy/lucy.py`:\*\* Gestor determinista de verificación de integridad, sellado y diagnósticos.

\* \*\*`lucy/hooks/`:\*\* Disparadores de arranque automático antes del primer turno de inferencia.



\---



\## 2. Requisitos de Sustrato



\* \*\*Intérprete:\*\* Python 3.10 o superior.

\* \*\*Dependencias:\*\* Ninguna (biblioteca estándar: `hashlib`, `pathlib`, `json`, `argparse`, `unicodedata`).

\* \*\*Compatibilidad:\*\* Multiplataforma (Linux, Windows, macOS, contenedores Docker).
